WELCOME TO PANTS PLACE 98
=========================

You are looking at a complete Windows 98-style desktop that runs
entirely in your browser.

THINGS TO TRY
-------------

1. MS-DOS Prompt
   Double-click the MS-DOS icon. It boots a real FreeDOS 7.10 virtual
   machine inside WebAssembly. Type DIR, MEM, or even INVADERS.

2. Winamp
   Open Winamp and press play. The playlist is built from the files in
   public/media. MIDI files are rendered with a General MIDI SoundFont;
   OGG files use the Web Audio API.

3. Internet Explorer
   The browser is your window into a fake 1998 internet. Start at
   http://www.pants.place/ and follow the webring.

4. Minesweeper
   Because every Windows 98 machine needs Minesweeper.

5. Display Properties
   Right-click the desktop, choose Properties, and try the color schemes.
   Hot Dog Stand is included, as the law requires.

ABOUT THIS MACHINE
------------------

  OS............ Pants Place 98 Second Edition
  CPU........... Pentium II 266 MHz (emulated vibes)
  RAM........... 32 MB (the FreeDOS VM gets all of it)
  Display....... 1024x768, 16-bit color
  Sound......... Sound Blaster 16 / General MIDI
  Browser....... Internet Explorer 4.0
  Media player.. Winamp 2.8

Start > Shut Down to power off.
