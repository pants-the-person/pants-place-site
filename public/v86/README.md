# v86 + FreeDOS assets

These files power the MS-DOS Prompt:

- `v86.wasm` — v86 x86 emulator, BSD-2-Clause. See `V86-LICENSE.txt`.
- `seabios.bin` — SeaBIOS, LGPL-3.0. Source: https://github.com/copy/v86/tree/master/bios
- `vgabios.bin` — SeaVGABIOS, LGPL-3.0. Source: https://github.com/copy/v86/tree/master/bios
- `freedos722.img` — FreeDOS 7.10 720k boot image, GPL-2.0. Source: https://copy.sh/v86/images/freedos722.img

The FreeDOS image boots to `A:\>` and includes the FreeDOS shell plus small games such as `invaders`, `snake`, and `tetris`.

FreeDOS project: https://www.freedos.org
