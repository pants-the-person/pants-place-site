# Media

Drop `.mid`, `.midi`, `.ogg`, or `.oga` files in this folder. The Winamp playlist is generated from this directory at build time and while the dev server is running.

Files are sorted by path. Subfolders are supported.

## Included demos

- `pants-theme.mid`, `dialup-blues.mid`, `overdrive-486.mid` — original demo MIDI files generated by `scripts/generate-media.mjs`.
- `chiptune-c64.ogg` — "Skiessi - C64" by Skiessi, licensed CC BY 3.0, via Wikimedia Commons. See `CREDITS.md`.

MIDI playback uses the bundled TimGM6mb General MIDI SoundFont in `public/soundfonts/`.
