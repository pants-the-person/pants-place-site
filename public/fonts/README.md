# Fonts

- `ms_sans_serif.woff2`, `ms_sans_serif_bold.woff2` — Pixelated MS Sans Serif, MIT, from 98.css.
- `Px437_IBM_VGA_8x16.ttf` — IBM VGA 8x16 remake, CC BY-SA 4.0, from The Ultimate Oldschool PC Font Pack (https://int10h.org/oldschool-pc-fonts/).

The VGA font is used by the MS-DOS Prompt. It is rendered at 16px for a crisp 8x16 cell.
